# MCI

Panel de Colocación · ASYS

- `Panel_Colocacion_ASYS_4.html`: panel autónomo en HTML.
- `index.html`: redirige al panel (para GitHub Pages).
- `vendor/`: copias locales de SheetJS 0.18.5, Chart.js 4.4.1 y PptxGenJS 3.12.0. El panel las usa primero y, si faltan, las carga desde cdnjs.

## Cómo abrirlo

- **En tu computadora:** descargá el repositorio completo (botón *Code → Download ZIP*), descomprimilo y abrí `Panel_Colocacion_ASYS_4.html` con doble clic. Mantené la carpeta `vendor/` junto al HTML. No necesita internet (salvo las fuentes tipográficas).
- **Como página web:** activá GitHub Pages en *Settings → Pages → Deploy from a branch*, elegí la rama y la carpeta `/ (root)`. El panel quedará en `https://g-asys.github.io/MCI/`.

> Abrir el archivo desde la vista de GitHub (github.com/…/blob/…) o desde "Raw" muestra el código, no la página.
